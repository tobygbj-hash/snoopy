# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Documentation hub under `docs/` (operations, architecture, commits, Raspberry Pi notes)
- [AGENTS.md](AGENTS.md) for AI coding agents
- [CONTRIBUTING.md](CONTRIBUTING.md), [COMMITS.md](COMMITS.md), and `.gitmessage` commit template
- `npm run serve` for local static hosting
- GitHub pull request template with privacy checklist

## [1.0.0] - 2026-05-31

### Added

- Voice browsing agent (`index.html`, `app.js`, `styles.css`)
- Chrome extension for reading Google AI summaries aloud
- Bookmarklet fallback when extensions are blocked
- Private handoff download and clear-screen controls
- GitHub Pages deploy workflow and `npm test` policy checks
