No Chrome extension needed

Snoopy summary reader for Toby.

Use this when your account blocks extensions. One bookmark button reads Google AI summaries aloud — the same warm Snoopy voice, without Developer Mode.

Install the bookmark button

  1. Show Chrome's bookmarks bar with Ctrl+Shift+B (or Cmd+Shift+B on Mac).
  2. Drag the orange button below onto the bookmarks bar.
  3. Search on Google until you see an AI Overview on the results page.
  4. Click the bookmark Read AI summary.
  5. Allow the microphone if Chrome asks (only used to hear “stop”).

Say stop while Snoopy is reading

  • "stop"
  • "hey Snoopy, stop"
  • "hi Snoopy" … then "stop"

Snoopy stops and says something kind, like "Of course, Toby. I have stopped reading for you."

Voice search does not need this bookmark

To search by voice, open the main Snoopy page index.html — that also works without any extension.

Privacy notes

  • The bookmark reads visible text from the current Google tab only.
  • It uses the browser's built-in speech synthesis.
  • It does not store data, call a backend, or send the summary anywhere.
  • If bookmarklets are blocked, only your account administrator can allow them.
