Snoopy summary reader for Toby.

If Chrome blocks Developer Mode, use this bookmark button to read a Google AI summary aloud from the current Google results page.

Install the bookmark button

  1. Show Chrome's bookmarks bar with Ctrl+Shift+B.
  2. Drag the orange button below onto the bookmarks bar.
  3. Open a Google results page that has an AI summary.
  4. Click the bookmark to hear Snoopy read the summary aloud.

Privacy notes

  • The bookmark reads visible text from the current Google tab only.
  • It uses the browser's built-in speech synthesis.
  • It does not store data, call a backend, or send the summary anywhere.
  • If your account blocks bookmarklets too, the account manager controls that setting.
