Enroll a new voice on the Pi

cd ~/snoopy/pi/speaker-id
source .venv/bin/activate
python enroll.py --id toby --name Toby
python enroll.py --id mum --name Mum

Restart the speaker bridge after enrolling: sudo systemctl restart snoopy-speaker-bridge
